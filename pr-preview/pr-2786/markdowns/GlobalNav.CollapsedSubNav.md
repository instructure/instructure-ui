# CollapsedSubNav



### Props

| Component | Prop | Type | Required | Default | Description |
|-----------|------|------|----------|---------|-------------|
| CollapsedSubNav | label | `string` | Yes | - | Screen reader text of the button that opens the SubNav again. |
| CollapsedSubNav | onExpand | `(event: SyntheticEvent) => void` | Yes | - | Called when the user clicks the strip or its button. |

### Usage

Install the package:

```shell
npm install @instructure/ui-global-nav
```

Import the component:

```javascript
/*** ES Modules (with tree shaking) ***/
import { CollapsedSubNav } from '@instructure/ui-global-nav/v11_7'
```
