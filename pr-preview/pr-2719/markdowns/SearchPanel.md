# SearchPanel



### Props

| Component | Prop | Type | Required | Default | Description |
|-----------|------|------|----------|---------|-------------|
| SearchPanel | view | `EditorView` | Yes | - |  |
| SearchPanel | searchConfig | `{ placeholder: string nextResultLabel: string prevResultLabel: string }` | Yes | - |  |

### Usage

Install the package:

```shell
npm install @instructure/ui-source-code-editor
```

Import the component:

```javascript
/*** ES Modules (with tree shaking) ***/
import { SearchPanel } from '@instructure/ui-source-code-editor/v11_7'
```
