# Card2


Use `<Card />` as a basic wrapper for grouping related content with padding,
border radius, shadow, and background color.

```js
---
type: example
---
<Card2 title='asd' content='asdadasdas'/>
```


### Props

| Component | Prop | Type | Required | Default | Description |
|-----------|------|------|----------|---------|-------------|
| Card2 | title | `ReactNode` | Yes | - |  |
| Card2 | description | `ReactNode` | Yes | - |  |

### Usage

Install the package:

```shell
npm install @instructure/ui-card
```

Import the component:

```javascript
/*** ES Modules (with tree shaking) ***/
import { Card2 } from '@instructure/ui-card/v11_7'
```
